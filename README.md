# movie-data-analysis
Indian Top Movies Box Office Collections Analysis
Project Overview
This project is an interactive Excel dashboard built using a custom dataset of the Top 50 highest-grossing Indian movies.
The dataset was collected and organized from IMDb and publicly available box office sources.
The dashboard provides insights into movie collections, ratings, languages, and overall box office performance.
Tools Used
• Microsoft Excel
• Pivot Tables
• Pivot Charts
• Slicers
• KPI Cards
• Data Cleaning & Validation
Key Features
• Total Movies KPI
• Total Box Office Collection KPI
• Average Collection KPI
• Highest-Grossing Movie KPI
• Interactive Slicers for filtering data
• Dynamic Charts and Visualizations
• Movie-wise and Language-wise Analysis
Insights Generated
• Top-performing Indian movies by box office collection
• Collection trends across different movies
• Distribution of movies by language
• Comparison of ratings and collections
• Identification of highest-grossing films
Dataset
Custom dataset containing the Top 50 highest-grossing Indian movies with details such as Movie Name, Collection, Rating, Language, and Release Year.
