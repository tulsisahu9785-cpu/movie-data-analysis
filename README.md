# 🎬 Indian Top Movies Box Office Collections Analysis

## 📌 Project Overview

The **Indian Top Movies Box Office Collections Analysis** is an interactive Excel dashboard that analyzes the **Top 50 highest-grossing Indian movies**. The project transforms raw movie data into meaningful business insights using dynamic dashboards, KPI cards, and interactive visualizations.

The dataset was compiled from **IMDb** and publicly available box office sources, enabling analysis of movie collections, ratings, languages, and overall box office performance.

---

## 🎯 Objective

- Analyze the box office performance of India's highest-grossing movies.
- Compare movie collections across different languages.
- Identify top-performing movies based on revenue and ratings.
- Create an interactive dashboard for data-driven insights.
